# Logo 添加工具 v0.1.0 MVP

这是第一个可用版本，重点是把核心流程跑通：

- 导入 PNG、JPEG、WebP Logo。
- 从 Logo 库选择图片并插入当前页。
- 在 PowerPoint 画布中拖拽和缩放 Logo。
- 读取当前选中 Logo 的位置和尺寸。
- 将该 Logo 的位置应用到整份 PPT。
- Windows 桌面版支持通过本机 PowerPoint COM helper 做批量写入。
- 同一份 PPT 中支持多个 Logo 或多个位置，不会互相覆盖。
- 包含 Windows 和 Mac 的本地旁加载脚本与中文安装说明。

压缩包下载后解压即可使用，详细步骤见压缩包内的 `README.md`。
