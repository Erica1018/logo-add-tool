# Logo 添加工具 v0.1.4

## 重点

这一版把 Mac 免安装交付版并入主仓库。以后 `logo-add-tool` 是唯一的功能项目；Mac 用户包从同一个仓库构建、发布和维护。

## 变化

- 新增 Mac 免安装打包命令 `npm run package:mac`。
- 新增 GitHub Pages 静态托管交付路径。
- Mac 安装脚本只写入当前用户 PowerPoint sideload 目录，不需要管理员权限。
- Mac 批量写入加入 Office.js 兼容模式。
- 超大 Logo 写入前自动等比压缩。
- Logo 库 IndexedDB 连接关闭后自动重试。
- 主构建不再依赖本地 Office HTTPS 证书。

## 验证

```powershell
npm run typecheck
npm test
npm run build
$env:LOGO_ADD_TOOL_URL="https://erica1018.github.io/logo-add-tool"
npm run package:mac
```
